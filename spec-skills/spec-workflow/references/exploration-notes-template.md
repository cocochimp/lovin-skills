# 探索笔记模板

当需要创建或更新 `exploration-notes.md` 时，使用以下模板。文件位于 `specs/<feature>/exploration-notes.md`。

## 定位

**决策日志**——记录探索过程中的关键决策和推理，作为后续 spec 和 design 的信息源。

| 该有的 | 不该有的 |
|--------|----------|
| 关键决策 + 原因 + 否决方案 | Java 代码 |
| 架构选择的推理过程 | 技术选型细节（框架版本、中间件配置） |
| 已解决/待解决问题列表 | 完整接口签名 |
| 调研发现（外部系统、第三方接口） | 伪代码 |
| 领域全景表 | 数据库表结构 |

## 模板格式

文件分为两部分：**结论**（按议题分类的确定性成果）和**过程**（探索中的思考轨迹）。

```markdown

<!-- 按 6 类展开章节，每类下包含决策条目和设计产出 -->
```

## 好的示例

```markdown
### 订单模型粒度
- **选择**：一个 SellOrder 对应多个 SellOrderItemOffer（商品行）
- **原因**：一个采购商一次下单可能买多个酒店/房型组合，商品行级别管理便于部分取消和独立履约
- **否决的替代方案**：一单一商品（简单但不支持组合下单场景）
```

## 坏的示例

```markdown
### 订单模型
用 SellOrderAggregate 类继承 BaseAggregate，字段包括 orderId(Long), status(OrderStatusEnum)...
@Value @Builder public class SellOrderItemOfferValue { ... }
```

**问题**：出现了 Java 代码和注解，这是 spec 或 design 的内容，不属于探索笔记。
