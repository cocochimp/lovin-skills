# 三个"科技成长指数"的真面目

> 2026-05-21 | 李继刚

纳指100、科创50、创业板指，三个名字摆一起，普通投资者觉得是同一类东西——科技、成长、高波动、高回报。

不是。

它们的差别，比"沪深300和中证500的差别"还大。一个是印钞机，一个是赌桌，一个是杂货铺。你以为在做选择题，其实在做判断题：你到底在买什么？

**先看一个数字：PE 86倍。**

科创50当前市盈率86倍，处于过去三年99.9%的历史分位。什么意思？过去800个交易日，只有今天比今天更贵。你买入的每一块钱，对应的年利润不到一分二。

纳指100呢？PE 34倍。同样是"科技指数"，你每投一块钱，利润回报是科创50的2.5倍。

但等一下——PE高就一定是泡沫吗？如果一个公司利润明年翻倍，今天PE 86明年就变43。问题在于：科创50的成分股，多数还在亏损或微利。PE 86倍不是"高增长的预支"，是"还没盈利的幻想定价"。

反观纳指那34倍PE背后站着什么：苹果年利润950亿美元，微软720亿，谷歌740亿。这些不是预期，是已经落袋的钱。34倍的价格买全球最能赚钱的公司群——贵吗？看跟谁比。

**切第二刀：看你买的到底是什么赛道。**

科创50的前十大权重股占了60%的仓位。翻开名单：寒武纪、海光信息、中芯国际、澜起科技、中微公司……十个里面八个是半导体。这不是"科技指数"，这是"中国芯片ETF"。你以为在分散投资科技板块，实际上把六成筹码押在了同一条产业链上。

纳指的前十也占47%，但横跨AI（英伟达）、消费电子（苹果）、云计算（微软、亚马逊）、广告（谷歌）、电动车（特斯拉）。五个不同的生意模式，五种不同的收入来源。某一个赛道崩了，其他的还撑着。

创业板指呢？100只股票，新能源30%、医药20%、科技20%、制造15%。像一个杂货铺——什么都有点，什么都不算特别集中。好处是不押单一赛道，坏处是缺乏鲜明的进攻方向。

**这意味着什么？**

假设明天半导体行业出利空——比如美国加强制裁、某个技术路线被证伪、或者仅仅是板块资金轮动——科创50可能一天跌5%，因为你60%的仓位在同一个篮子里。纳指呢？英伟达跌了，苹果和微软不一定跟。创业板指？新能源跌了，医药可能还涨。

数据验证了这个逻辑。过去三年，科创50的最大回撤是-44.8%——接近腰斩。纳指最大回撤约28%，创业板约35%。波动率：科创31.3%，纳指22%，创业板28%。

但科创50近一年涨了54%，比纳指的37%还猛啊？

对。赌桌上赢钱的时候当然比稳健投资赚得快。问题是你能不能扛住中间那45%的回撤。一个普通投资者，账户从100万跌到55万的时候，有多少人能拿住？大部分人在最低点割肉，然后眼看着它涨回来。

**夏普比率说了真话。**

纳指夏普比率约0.7，科创50只有0.44。同样承担一个单位的风险，纳指给你的回报比科创50高60%。科创50的高收益，是用不成比例的高风险换来的。这不叫"回报高"，叫"赌赢了"。

**再往下一层：盈利的底色。**

三个指数看起来都在涨，但涨的原因完全不同。

纳指涨，因为成分股年年在赚更多的钱。苹果的利润从2021年的950亿涨到现在，微软的云业务还在30%增速。估值没怎么扩张，是利润在推着股价走。这叫"赚盈利的钱"。

科创50涨，靠的是估值扩张。利润没怎么涨（很多公司还在亏），但市场愿意给更高的PE。从23倍涨到86倍——三年翻了将近四倍。这叫"赚情绪的钱"。情绪来得快，去得也快。

创业板指介于两者之间。宁德时代、迈瑞医疗这些龙头确实在赚钱，但体量和增速跟美股科技巨头不在一个量级。

**合起来看。**

同样叫"科技成长指数"，你面对的是三种完全不同的东西：

纳指100是一台验证过的印钞机。贵一点，但你知道它明天还会印。科创50是一张彩票——赔率高，但中奖概率由半导体国产替代的进度决定，而这个进度谁也说不准。创业板指是一个比较平衡的篮子，不惊艳也不惊吓。

如果你只能选一个长期持有，数据指向的答案很清楚。但如果你问我确不确定——70%确定。剩下30%留给"万一中国半导体真的在未来两年爆发"这个可能性。

确定性本身，就是值得付费的东西。
