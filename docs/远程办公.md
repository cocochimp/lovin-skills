# 远程办公

> 2026-05-29 | 李继刚

远程办公比坐班更高效。

这句话你大概听过一百遍。疫情之后它几乎成了共识——省通勤、少干扰、自由安排。听上去全是好处。但共识听多了就不再被检验。放到台面上，切开看看。

**效率是谁的效率？**

说"远程更高效"的人，通常在描述自己的体感：没人拍肩膀，会议少了，代码写得顺。这是真的。一个需要深度专注的活儿，在家确实产出更高。

但把镜头拉远。产品经理在群里@你，三小时没回。设计师改了方案，你第二天才看到。你快了，但齿轮和齿轮之间的咬合松了。

"远程更高效"偷偷做了一件事：把"我的效率"等同于"效率"。个人产出和组织产出，不是同一个变量。一台发动机转速拉满，变速箱没跟上，车不会更快。

**坐班的低效，真是办公室造成的吗？**

办公室里有噪音、闲聊、无意义的会议。谁都烦。但这些不是"办公室"这个物理空间的属性，是管理方式的属性。

一个管理混乱的团队远程之后会怎样？无效会议变成无效视频会。拍肩膀打断变成@全体成员。八卦从茶水间搬到微信群。低效没有消失，换了个地址而已。

你以为你在逃离办公室。其实你在逃离一种管理方式。地点是表象，管理才是那个变量。

**那为什么在家"感觉"高效？**

因为你终于能控制自己的环境了。在公司，空调温度不由你，会议时间不由你，旁边工位的电话声不由你。回到家，一切你说了算。

这种控制感带来的舒适，很容易被误读为效率提升。你确实更舒服了。但舒服和高效之间，隔了一层。

话说回来——控制感也不全是幻觉。一个人能自主安排节奏，把最难的任务放在自己最清醒的时段，产出会上去。这一点不必否认。问题是，它被高估了。

**这里有个交换。**

你用协作的摩擦成本，换来了个人的专注收益。划不划算，取决于你的工作有多大比例是独立完成的。

写代码、写文章、做数据分析——独立性高，远程赢。产品对齐、危机处理、新人带教——协作密度大，坐班赢。

所以"远程办公比坐班更高效"不是一个判断，是一个缺了关键变量的方程。把工种、协作密度、管理水平这些变量抽掉，剩下的只是一个让人舒服的口号。

**回到开头。**

那句话还站着吗？站着，但变了形。

准确的版本大概是这样：对于高独立性的知识工作，在管理本身不拉垮的前提下，远程办公降低了环境干扰的概率。

不性感，但诚实。

大多数人说"远程更高效"的时候，真正想说的其实是——我终于不用忍了。这不是效率的胜利，是忍耐的终止。一个需要靠逃离才能正常运转的系统，病灶从来不在地点。
