# 起点

大公司越大越难创新。这句话说了几十年，几乎没人反对。但"难"在哪？不是缺钱，不是缺人，不是缺技术。谷歌、微软、亚马逊什么都不缺，照样在关键转折点上慢半拍。

钱、人、技术都在，创新却不在。问题不在资源，在别处。

往下看。

# 第一层：免疫

大公司不是忘了创新，是身体在排斥创新。

一个新想法要活下来，得过多少关？立项审批、预算评审、合规审查、跨部门协调、季度汇报……每一关的设计目的都一样：降低风险。

这不是官僚主义的副作用。这是组织长出来的免疫系统。它的功能和生物免疫系统一模一样——识别异物，消灭异物。新想法就是异物。

小公司没有这套系统。不是因为它们更聪明，是因为它们还没长出来。一个五个人的团队不需要审批流程，就像婴儿不需要复杂的免疫系统——还没遇到足够多的病原体。

公司越大，遇到的"病原体"越多——失败的项目、亏损的赌注、监管的处罚——免疫系统就越强。越强，杀新想法就越快。

但免疫系统是谁在操作？

# 第二层：筛选

是人。具体说，是被筛选出来的那批人。

大公司的晋升机制有一条隐性标准：不犯错。你可以不出彩，但不能出事。十年不犯错的人升到VP，三年做出两个突破但搞砸一个项目的人早就走了。

这不是哪家公司的问题，是规模的必然。管一万人，你需要可预测的管理者。"可预测"和"有创造力"是两个方向的力。筛选机制只能优化一个变量，它选了可预测。

所以坐在决策位上的人，恰好是最不可能批准冒险的人。不是他们不想，是他们的整个职业生涯都在训练他们不要这样做。让一个靠规避风险升上来的人去拥抱风险，等于让一个靠节食瘦下来的人去参加吃热狗大赛。

但为什么筛选机制一定选"可预测"？

# 第三层：度量

因为大组织必须度量绩效。不度量就无法分配资源，无法考核，无法协调。

度量需要指标。指标必须是可观测的、可比较的、可量化的。"这个人今年没搞砸任何项目"——可量化。"这个人有一个可能改变行业的直觉"——不可量化。

度量系统天生只能看见已经存在的东西。它能衡量上季度的收入、用户增长、bug修复数。它看不见一个还没成形的可能性。

创新在成功之前，在度量系统里的样子是：花了钱，没产出，指标难看。和浪费一模一样。度量系统无法区分"正在酝酿的突破"和"纯粹的浪费"，因为两者在当下的数据表现完全相同。

公司越大，越依赖度量来协调。越依赖度量，越看不见创新。

但为什么度量只能看见已有的东西？

# 第四层：可述

因为度量的前提是描述。你只能度量你能描述的东西。

管理一万人，你需要把目标写成文档，把流程画成图，把成果填进表格。一切必须可述——能用语言和数字说清楚。

创新，在它发生之前，恰好是不可述的。如果你能清楚描述一个创新，它就不是创新了——它是已知事物的重新排列。真正的新东西，在它出现之前，语言里没有它的位置。

规模要求可述性。创新是不可述的。这不是管理问题，是语言的边界。

维特根斯坦说过一句被引用烂了的话，但它在这里精确得像手术刀：凡不可说的，必须沉默。大公司的整个运作建立在"说"之上——汇报、对齐、同步、文档。对于不可说的东西，组织只能沉默。沉默就是不投入、不关注、不存在。

但为什么规模一定要求可述性？

# 第五层：秩序

因为组织的本质就是秩序。

一家公司是什么？是一群人按照某种规则协作。规则就是秩序。公司越大，秩序越复杂，越精密，越不容许例外。

秩序的功能是把混沌变成可预测。把不确定的人类行为，压进确定的流程和结构里。这是组织存在的全部理由——如果不需要秩序，就不需要组织，几个人松散合作就够了。

创新是什么？是引入新的不确定性。是打破现有模式，创造之前不存在的东西。

一个致力于消灭不确定性的系统，遇到了一个本质就是不确定性的事物。这不是冲突，是矛盾。结构性的、不可调和的矛盾。

所以"大公司创新"这个词组本身就是一个悖论。组织的存在是为了建立秩序，创新的本质是打破秩序。你在要求一个东西同时做两件相反的事。

还能再往下吗？

# 第六层：同一

能。最后一层。

秩序要求一个东西是它自己。A是A。流程是流程，部门是部门，产品是产品。这是协调的基础——如果A随时可能变成B，你没法围绕A做任何计划。

创新要求一个东西变成不是它自己的东西。A变成B。旧产品变成新产品，旧模式变成新模式。

A不能在保持A的同时变成非A。

这是逻辑的同一律。不是管理学的问题，不是组织行为学的问题，是逻辑本身的限制。

一个系统越大，它的"A"就越庞大、越坚固、越自洽。它越是A，就越不可能成为非A。

所以大公司越大越难创新，不是因为它们做错了什么。是因为"大"和"新"在逻辑上互斥。大是对现有秩序的巩固，新是对现有秩序的否定。你不能同时巩固和否定同一个东西。

创新从来不是从A内部发生的。它发生在A的边缘，在A还没覆盖到的地方，在A不是A的缝隙里。车库、咖啡馆、两个人的小团队——不是因为这些地方有什么魔力，是因为这些地方还没有足够的秩序去排斥新东西。

大公司能做的最接近创新的事，是在自己体内制造一小块"非A"——独立团队、臭鼬工厂、内部创业。本质上是在自己身体里挖一个洞，假装那里不是自己。有时候管用。但免疫系统迟早会找到它。
