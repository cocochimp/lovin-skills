# 通信、半导体、电子：科创板 vs 创业板对比

## 核心定位差异

| | 科创板 | 创业板 |
|---|---|---|
| 定位 | "硬科技"，强调核心技术突破 | "三创四新"，成长性优先 |
| 审核标准 | 对研发投入/专利有硬性要求 | 更看重业绩增长 |
| 上市门槛 | 允许未盈利企业上市 | 一般需要盈利 |

## 半导体（含存储、芯片）

| | 科创板 | 创业板 |
|---|---|---|
| 企业类型 | 设计+设备+材料+EDA，偏上游、偏"卡脖子" | 偏下游应用、封测、模拟芯片 |
| 代表公司 | 中芯国际、海光信息、中微公司、澜起科技、寒武纪、华大九天 | 卓胜微、圣邦股份、北京君正 |
| 特点 | 研发投入大、很多上市时未盈利、估值高 | 盈利相对稳定、细分赛道龙头 |

> 科创板是半导体的绝对主场，占科创50指数50-55%权重。

## 通信

| | 科创板 | 创业板 |
|---|---|---|
| 企业类型 | 通信芯片、卫星通信、量子通信等前沿技术 | 光模块、网络设备、通信服务等偏应用端 |
| 代表公司 | 翱捷科技（通信SoC）、国盾量子 | 中际旭创、新易盛、锐捷网络 |
| 特点 | 技术门槛高、商业化早期 | 已有成熟收入、订单驱动 |

> 光模块龙头基本都在创业板（中际旭创、新易盛）。

## 电子

| | 科创板 | 创业板 |
|---|---|---|
| 企业类型 | 高端检测设备、精密传感器、先进显示 | 消费电子、PCB、被动元器件、面板 |
| 代表公司 | 华兴源创（检测）、格科微（CIS） | 沪电股份、深南电路、立讯精密、京东方 |
| 特点 | 设备/器件级，技术壁垒高 | 规模效应驱动，和终端需求紧密挂钩 |

## 一句话总结

- 科创板 → 技术原点（芯片设计、设备、EDA、前沿通信）→ 高研发、可能不赚钱、高波动
- 创业板 → 商业落地（光模块、PCB、消费电子、应用端）→ 有利润、估值相对合理、成长驱动
