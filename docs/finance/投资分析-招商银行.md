# 投资分析：招商银行

**日期：** 2026-05-07  
**标签：** #投资 #银行 #招商银行

---

## 一、这是什么

| 维度 | 内容 |
|------|------|
| 项目名称 | 招商银行（600036.SH / 03968.HK） |
| 赛道定义 | 中国中产阶级财富管道的垄断运营商 |
| 阶段 | 成熟期——从高速增长切换到存量深耕 |
| 市值 | 约 9720 亿人民币（2026.05） |
| 数据快照 | 总资产 13.07 万亿，零售 AUM 17.86 万亿，2.1 亿客户，ROE 14% |

**赛道定义的逻辑：** 招行不是一家"银行"，它是中国 5200 万金葵花以上客户（资产 50 万+）的财富管道。这些人的钱进来、流转、增值、花掉，都在这根管道里完成。银行牌照是它的护城河，但它卖的不是存贷利差，是管道使用权。

---

## 二、秩序创造机器判定

### 飞轮在不在转？

转着，但在减速。

招行的核心飞轮：

> 优质零售客户 → AUM 增长 → 低成本负债 → 高息差 → 更多利润 → 更好的产品和服务 → 吸引更多优质客户

**证据：**

- 零售 AUM 从 2020 年的 8.9 万亿增长到 2025 年末 17 万亿+，五年翻倍。飞轮在转。
- 金葵花以上客户数从 2023 年 464 万增长到 2024 年 524 万（+12.8%）。高净值客户在加速聚集。
- 但收入连续两年零增长（2024 年 -0.48%，2025 年约持平），利润只增 1.2%。飞轮转动的效率在下降——AUM 在涨，但变现能力在萎缩。

**根本原因：** NIM（净息差）从 2023 年的 2.15% 压到 2025Q3 的 1.87%。央行降息是外力，但这意味着飞轮的"高息差"环节被削弱了。飞轮结构还在，但输出功率在降。

### 冲击后变强还是变弱？

历史上经受过三次重大冲击：

1. **2015 年股灾 + 利率市场化：** 零售银行体系稳住，同期大量中小银行靠同业加杠杆，招行反而获得存款回流。**变强。**
2. **2020-2022 年房地产暴雷：** 房地产 NPL 达 4.94%，但整体 NPL 仅 0.95%，拨备覆盖率 412%——用厚垫子吸收了冲击，没伤到骨头。**扛住。**
3. **2023-2025 年 NIM 持续下行 + 资本市场低迷：** 这是当前正在经历的冲击。财富管理收入 2024 年跌 14.3%，但 2026Q1 财富管理手续费反弹 +25.4%。还在消化中，但有恢复迹象。

**判断：** 招行对冲击的反应模式是"扛住→慢恢复"，不是"吃掉冲击变更强"。它是厚壁容器，不是反脆弱体。

### 资源是被推过来的，还是自己来的？

**自己来的。** 这是招行最核心的特质。

- 零售客户 2.1 亿，靠的不是地推网点铺设（招行网点数远少于四大行），而是产品体验和品牌引力。
- 金葵花客户 +12.8% 是"自己来的"——高净值客户选招行不是因为被客户经理拉来，而是因为别处体验更差。
- 低成本存款占比高，存款成本率持续低于行业——钱主动流向它，而非它去抢。

"不推而聚"在招行身上是真实存在的，这在中国银行业极为稀缺。

### 综合判定

**秩序创造机器，但处于功率下降期。**

飞轮结构完整且经过验证，资源确实自己来，但外部环境（利率下行、监管压费）正在压缩飞轮的输出。它是一台好机器，问题是燃料（息差 + 费率）在变贵。

## 三、创生公式

> 招行 = 品牌信任 → 聚集优质零售客户 → 低成本负债 → 息差利润 + 财富管理手续费 → 投入产品体验 → 巩固品牌信任

**验证程度：**

- 这个公式从 2004 年马蔚华推零售转型开始跑，到 2024 年已验证 20 年。
- 中间经历三任行长（马蔚华、田惠宇、王良），公式没变，说明不依赖某个人。
- Q1 2026 收入恢复正增长（+3.85%），财富管理手续费大幅反弹，说明公式没坏，只是暂时被压了。

**别人在跑相似公式吗？**

- 平安银行试过，但 ROE 只有 ~10%，NPL 高于招行，体量只有招行一半。形似但功率不够。
- 宁波银行在小微领域跑出了类似的"优质客户聚集"效应，但赛道不同。
- 四大行不跑这个公式——它们跑的是"国家信用 + 网点覆盖 + 政策业务"的另一套逻辑。

**招行的公式在中国没有真正的第二个跑通的人。**

## 四、市场看见的 vs 我们看见的

### S 曲线位置

**平台期前段。**

零售银行的渗透已经到顶（2.1 亿客户），增长动力从"获客"切换到"单客价值提升"。AUM 还在涨（+11% YoY），说明平台期内仍有增长空间，只是增速逻辑变了。

### 市场在用什么旧眼睛看它？

市场贴的标签："中国银行股——NIM 压缩——利率下行受害者"。

**这个标签遮住了什么：**

1. 招行的真正资产不是贷款，是 17.86 万亿 AUM 背后的客户关系。这些客户关系的价值无法用 P/B 定价。
2. 当前 0.75x P/B 意味着市场认为招行未来的 ROE 将低于资本成本——但招行 ROE 14.5%，远高于任何合理的 CoE 假设（8-10%）。这是定价错误。
3. 市场把招行和"银行板块"放在一起看。但招行的真实可比对象应该是财富管理平台（嘉信理财 P/B 4x+），不是四大行（P/B 0.5-0.6x）。

**认知折价信号：**

- P/B 0.75x 对应的隐含假设是"长期 ROE 降到 8%以下"，但过去 20 年从未发生过
- 银行分析师用 Gordon 模型，假设增长率为零，完全忽略 AUM 增长的期权价值
- "像银行但又不完全像银行"——这个描述精确命中了认知折价的第三个信号

### 它控制了什么别人拿不走的东西？

1. **客户习惯：** 2.1 亿客户的工资卡、还贷卡、理财账户绑定在招行体系里。迁移成本极高——不是技术上难，是行为惯性。
2. **品牌心智：** "办银行卡选招行"在中国城市白领中已成为默认选项。这种心智位置需要 20 年积累。
3. **数据壁垒：** 17.86 万亿 AUM 对应的客户消费行为、资产配置偏好、风险特征数据。这些数据越用越好，用于精准营销和风控。

这种控制是动态的——客户越多、数据越多、服务越精准、客户越离不开。

### 它在搭哪趟便车？

搭的是 **理解成本坍缩** 的便车。

中国居民从"存银行"到"做理财"的认知升级还在进行中。居民储蓄 130 万亿+，进入财富管理市场的比例仍在提升。招行作为最受信任的财富管理渠道，是这个认知升级的最大受益者。

但这趟便车的速度不确定——如果资本市场持续低迷，居民可能从"做理财"退回到"存银行"。2024 年财富管理收入 -14.3% 就是这个风险的体现。

## 五、换不换

### 交换建议

**建议投资。**

### 如果投资

- **仓位建议：** 核心仓位（5-10%），适合作为组合中的"防守型价值锚"
- **估值锚：** 合理 P/B 在 1.0-1.2x（对应股价 50-60 元），当前 0.75x 有 30-60% 向上空间
- **条件：** 如果 NIM 企稳在 1.8% 以上，且财富管理收入恢复正增长，估值修复的催化剂就成立

### 核心假设与退出信号

| 假设 | 退出信号 |
|------|----------|
| NIM 不会跌破 1.6% | 连续两个季度 NIM 环比降幅超过 10bps |
| 零售 AUM 保持 8%+ 年增速 | 年度 AUM 增速跌至 5% 以下 |
| 资产质量可控（NPL < 1.2%） | NPL 突破 1.2% 或拨备覆盖率跌破 300% |
| 财富管理收入恢复增长 | 连续四个季度手续费收入负增长 |
| 中国不发生系统性金融危机 | 银行间市场流动性事件或大型银行出险 |

### 未解问题（按优先级）

1. 利率下行周期还要持续多久？如果 LPR 继续下调 50bps+，招行的 NIM 护城河能否守住 1.7%？
2. AI 对财富管理行业的颠覆路径是什么？智能投顾会削弱还是加强招行的渠道价值？
3. 新管理层（王晓青）的战略执行力如何？"价值银行"转型是真转还是口号？
4. 信用卡业务的结构性萎缩（消费降级 + 数字支付分流）会到什么程度？
5. 房地产尾部风险是否已完全暴露？隐性地方债风险敞口有多大？

## 最后一句

招商银行是一台经过 20 年验证的秩序创造机器——它把中国中产阶级散落的财富组织成了一个自运转的飞轮。机器没坏，只是当前的宏观环境在限制它的输出功率。0.75 倍 P/B 的价格，买的是一台暂时降功率运行但结构完好的引擎。
