## 行业分布分析

- **银行**: 工商银行、招商银行、农业银行 — 低PE + 低PB + 高股息，是当前A股最明显的价值洼地
- **保险**: 中国平安 — PE仅8.2，PB刚过1倍，盈利修复中
- **券商**: 华泰证券、国泰海通、东方证券、中信证券 — PB接近1倍，估值处于历史低位
- **基建/能源**: 中国电建、中国石油、中国中车 — 央企改革 + 分红提升预期
- **消费/制造**: 美的集团、伊利股份 — 白马龙头，估值回到合理区间
- **周期**: 中国铝业、TCL科技 — 受益于行业景气周期

## 风险提示

1. 银行板块虽然估值低，但需关注资产质量和息差收窄风险
2. 周期股（石油、铝业）受大宗商品价格波动影响大
3. 券商业绩与市场活跃度高度相关，波动性较大
4. 本次筛选基于PB/PE定量指标，建议结合ROE、现金流、分红率等做进一步个股深度分析
5. **所有分析仅供参考，不构成投资建议**
