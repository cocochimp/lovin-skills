# 996 与跃迁的反面

> 李继刚 | 2026-04-29

观点：996 是年轻人阶层跃迁的必经之路。

这话有一个藏得很深的前提：时间能换阶层。

想想这个画面。一个年轻人，早九晚九，一周六天，坐在工位上。写代码、做表格、回消息、开会、再写代码。三年后，初级升中级，工资涨了 40%。他觉得自己在跃迁。

但 40% 是跃迁吗？月薪一万到一万四，房租还是五千，通勤还是一小时。换了个更大的工位，坐得更久。这不叫跃迁，叫加薪。跃迁是从出卖时间到拥有资产，从打工到不打工。涨薪和跃迁之间，隔着一道结构性的墙。

996 的逻辑链看着完整：投入更多时间 → 产出更多价值 → 获得更多回报 → 阶层跳跃。但每一环都漏。

先看第一环。多出的时间干了什么？大部分 996 不是在做高杠杆的事——不是在学新技能、建人脉、想商业模式。是在重复。同样的需求，同样的流程，同样的会议，只是多转了几个小时。重复不产生跃迁，重复产生熟练。熟练值钱，但没那么值钱。

第二环也漏。就算你真的产出了更多价值，回报归谁？你写的代码、做的方案、谈的客户，利润的大头归公司。你拿工资，不拿股权。用自己的时间给别人的资产增值——这不是跃迁的路径，是跃迁的反面。

话说回来，有人确实靠 996 起来了。早期加入创业公司，拼命干，公司上市，期权变现。这种故事存在。但注意——起作用的不是 996 本身，是押对了公司。996 是表象，赌注才是因。同样 996，在一家没前途的公司耗三年，什么也换不到。

那真正的阶层跃迁靠什么？

靠杠杆。代码是杠杆，写一次，跑无数次。资本是杠杆，钱替你干活。影响力是杠杆，一句话触达一万人。打工是反杠杆——产出和时间线性绑定，多一小时多一点，少一小时少一点，永远一比一。

996 不但不提供杠杆，还吃掉了你找杠杆的时间。晚上九点下班，回家洗澡倒头睡，周六继续。什么时候读书？什么时候想？什么时候做自己的东西？全被占了。一个人的带宽被塞满，就没有余量去碰那些真正能改变位置的事。操作系统跑满了后台进程，前台什么也启动不了。

所以这个观点翻过来，结论正好相反：996 是阶层固化的工具，不是阶层跃迁的路径。它把年轻人的全部精力锁死在「时间换钱」的循环里，刚好够活，不够翻身。

谁在鼓吹 996？拥有资产的人。他们的跃迁早就完成了，靠的恰恰不是给别人打工到晚上九点。

一个人告诉你吃苦是福，先看看他自己吃不吃。
