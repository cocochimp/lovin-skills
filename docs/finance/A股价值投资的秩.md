# A股价值投资的秩

> date: 2026-04-29 星期三 13:46

A股市场里自称做价值投资的人，说出来的话五花八门。有人盯着市盈率，有人研究护城河，有人看管理层，有人算自由现金流，有人等市场恐慌时抄底，有人死拿不动。财报分析、行业研究、估值模型、仓位管理、逆向思维、安全边际——概念多到可以写一本词典。

但这些概念不是平行的。大部分是几根更深的线长出来的枝叶。在A股做价值投资，真正独立的生成器只有三根。

第一根：**现金流**。

一家公司值多少钱？所有估值方法拆到底，答案都是同一句话：它未来能给你赚多少真金白银，折算到今天值多少。这就是现金流折现的意思，虽然没人真的拿计算器按出一个精确数字，但脑子里转的永远是这件事。

市盈率是现金流的简化版——假设利润约等于现金流，拿价格除一下。市净率是另一个角度——资产能产生多少现金流。ROE 是效率指标——同样的本钱，谁能榨出更多现金。自由现金流才是最诚实的——利润表可以修饰，但钱进没进账户骗不了人。

A股有个特殊现象：很多公司利润好看，但现金流很差。应收账款堆成山，利润全是纸上富贵。所以在A股做价值投资，第一课就是学会区分"赚到了利润"和"收到了钱"。茅台为什么被封神？先款后货，现金流比利润还好。这在A股是稀缺品。

第二根：**定价偏差**。

知道一家公司值多少钱还不够。你得在它便宜的时候买。

格雷厄姆叫它"安全边际"——你算出值 100 块，60 块买入，中间那 40 块就是你的安全垫。但问题是，为什么会出现便宜的机会？

因为市场会犯错。而且A股犯错的频率和幅度，比成熟市场大得多。

散户占比高，情绪波动剧烈。一个利空消息能把股价砸到不可思议的位置。政策一句话，整个板块腰斩。牛市时鸡犬升天，熊市时泥沙俱下。这种大开大合的波动，对价值投资者来说既是诅咒也是礼物——你得扛得住过程中的痛苦，但正是这种痛苦制造了便宜货。

逆向投资、左侧交易、在别人恐惧时贪婪——这些说法本质上都在描述同一件事：识别定价偏差，并且有胆量利用它。

第三根：**制度摩擦**。

前两根线放在任何市场都成立。但A股有第三根线，是它独有的，也是很多从教科书学价值投资的人栽跟头的地方。

A股不是一个纯粹由供需决定价格的自由市场。它运行在一套独特的制度框架里，这套框架会系统性地扭曲前两根线的作用方式。

IPO 审核制（虽然在改革）意味着上市本身就是稀缺资源，壳价值长期存在。这让很多烂公司的股价远高于其现金流能支撑的水平。退市机制不畅，垃圾股不死，价值回归的路被堵了一半。

国有股东的存在让很多公司的治理结构和纯市场化公司不同。大股东的利益不一定和小股东一致——有时候公司赚了钱，但分红很少，钱去了你看不到的地方。

政策对市场的影响是直接的、突然的、有时是决定性的。一个行业可以因为一纸文件从天堂到地狱。教培、互联网平台、房地产——都是活生生的例子。你用现金流算出来值 200 块的公司，政策一变，未来的现金流直接归零。

所以在A股做价值投资，光会算账不够，你还得理解这台机器的运行规则。制度摩擦不是噪音，它是信号的一部分。

三根线，就这些。

你可能会问：行业研究呢？行业研究是为了更准确地预测现金流，挂在第一根线上。管理层分析呢？好的管理层能创造更多现金流、坏的管理层会侵蚀现金流，还是第一根线。仓位管理呢？仓位管理是在定价偏差不确定时控制风险，挂在第二根线上。政策分析呢？那是第三根线的具体操作。

有意思的是，这三根线之间有张力。

现金流分析让你觉得一家公司很便宜。但定价偏差告诉你，便宜可能会更便宜——市场的非理性可以持续很久。而制度摩擦可能直接改变游戏规则，让你精心计算的现金流变成废纸。

在A股赚到钱的价值投资者，不是在某一根线上做到极致的人，而是同时看清三根线、并且知道什么时候哪根线权重更大的人。牛市里制度摩擦的影响被掩盖，现金流好的公司和差的一起涨。熊市里定价偏差放大，好公司也被错杀。政策转向时，前两根线的分析全部暂停，第三根线一票否决。

三根线，三个维度。A股价值投资就是在这个三维空间里找定位。

```
                  [现金流]
                 /    |    \
           (折现)  (验证)  (预测)
              /       |       \
             v        v        v
          估值      财报      行业
            \        |        /
             \       |       /
              \      |      /
               \     |     /
    [定价偏差]<--- 张力 --->[制度摩擦]
    市场情绪犯错        规则扭曲定价
    制造买入机会        改变现金流本身

    三者关系：
    现金流 --算出--> 内在价值
    定价偏差 --制造--> 买入机会（价格 < 价值）
    制度摩擦 --扭曲--> 现金流（+改变规则）
                  --放大--> 定价偏差（+政策驱动波动）
```

下次看一只A股，问三个问题就够了：它未来能收到多少真钱？现在的价格偏离真实价值多远？有没有制度层面的力量在扭曲前两个答案？三个问题答完，判断就有了。
