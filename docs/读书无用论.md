# 读书无用论

> 2026-05-29 | 李继刚

"读了那么多书，有什么用？"

这句话每隔几年冒一次头。说的人手里通常攥着一个活例子：隔壁老王初中没毕业，现在开三家店；你读到研究生，还在还房贷。例子是真的。结论跳了一步。

**它把"用"钉死在一个维度上：变现。**

一件事有没有用，先得定义"用"是什么。读书无用论里的"用"，约等于赚钱。用这把尺子量，读书确实经常不及格。一个人花四年读完大学，起薪可能不如早他四年进厂的同学。短期账面上，读书亏了。

但这笔账有个隐藏前提：它假设人生是一笔短期交易。

拉长到二十年看。那个早进厂的人，天花板大概率在第五年就碰到了。读了书的人，天花板至少高几层——不是学历本身值钱，是他多半学会了一件事：**在陌生问题面前不慌。** 读书训练的不是知识储备，是处理未知的能力。像给操作系统打补丁，平时感觉不到它在跑，但遇到新问题时，系统不崩。

但等一下——如果真是这样，为什么那么多读了书的人，系统好像也没升过级？

因为大多数人读书的方式，是往内存里堆数据。读完一本，记了几个金句，发了条朋友圈，完事。这不叫读书，叫缓存。缓存不经编译，过一阵就被清掉，什么都不剩。

**真正有用的读书，是编译，不是缓存。**

编译的意思：把作者的思路拆开，用自己的问题重新跑一遍。跑通了，是你的了。跑不通，卡在哪，那个卡点就是收获。绝大多数人跳过了这步。读了，没编译。然后断言：没用。

这像买了一堆菜全塞冰箱放到发霉，然后说买菜不如叫外卖。菜没问题，你没做饭。

话说回来，读书无用论也不全错。

它戳中了一个真问题：**很多人用读书逃避思考。** 书越读越多，成了安慰剂——觉得自己在进步，其实只是在消费别人的思考成果。读完了觉得"说得真好"，合上书，什么也没变。这种读书，确实没用。不是书没用，是那个读法没用。

但读书无用论把这层洞察推太远了。它看到假读书的无用，就否定了真读书的价值。洗澡水和孩子一起倒了。

这种论调为什么传播得快？因为它提供了一种**廉价的自洽**。不读书的人听了舒服——反正读了也白读。读了书但没变化的人也舒服——不是我不行，是书不行。两拨人同时得到安慰，没人需要面对那个更扎的事实：问题不在读书有没有用，在你有没有真的在想。

读书无用论的本质，不是对书的判断，是对思考的逃避。它用"无用"两个字，把一个关于自己的问题，变成了一个关于书的问题。锅甩得干净利落。

从底回看开头那句话。它还站着，但变形了。表面说的是书，底下说的是思考的偷懒。一个不肯编译的人，给他一整座图书馆也是缓存溢出。一个真在想的人，一本书就够长出新东西。

有没有用，从来不是书的事。
