## 二、亮点

**1. 写作风格引导是教科书级别的**
- `style-guide.md` 用"禁止表"替代了空泛的"写得好一点"，直接告诉模型什么不能做（"让我们一起xxx"、"值得深思"、"赋能/抓手"）
- 主观/客观两套写作约束设计精妙——同一个选题可以走两条路，用户有选择权
- 红色加粗的`**「关键结论」**`标注规范很聪明，既给读者视觉锚点，也约束了模型不会通篇加粗

**2. 交互节奏控制得当**
- 5 个确认点（选题→标题→初稿→封面方案→发布清单），不会一口气跑完
- "更换"机制从缓存取，不重新抓取，体验流畅

**3. 端到端闭环是真正的护城河**
- 选题（抓取/搜索）→ 写文 → 配图（HTML模板+Playwright截图）→ 发布（微信API草稿），全链路自动化
- `publish.js` 自行实现 multipart 编码避免额外依赖，很克制

**4. 图片质量自审机制**
- 5 项检查清单 + 最多 3 轮迭代 + Read 图片自审，这比大多数 skill "截完图就完事"高出一个维度

## 三、问题与改进建议

### 问题 1：Description 触发力不足（-2分）

- [ ] **待改进**

当前：
> 公众号自媒体内容生产全流程。触发词："公众号"、"写公众号"、"gzh"、"/gzh-writes"。

**问题**：用户说"帮我写篇文章发到公众号"、"写个商业分析"、"帮我做个封面图"这类变体时可能不触发。

**建议**：加入更多近义触发场景和"推动性"描述：
> 公众号自媒体内容生产全流程。触发词：...。当用户提到写公众号文章、自媒体内容、微信公众号发布、生成公众号封面图，或任何涉及"选题→写文→配图→发布到公众号"的需求时，都应使用此技能。即使用户只说"帮我写篇文章"，只要上下文暗示目标是公众号，也应触发。

---

### 问题 2：数据图模板过于骨架化（-3分）

- [ ] **待改进**

`data_template.html` 只提供了一个带噪点的浅灰底 + `{{CONTENT_HTML}}` 占位符，所有数据可视化的 CSS/HTML 都需要模型从零设计。这意味着：
- 每次生成的数据图风格可能不一致
- 模型花大量 token 在写 CSS 上
- 质量完全取决于模型当次的发挥

**建议**：提供 2-3 个数据图子模板（对比卡片、数据表格、时间轴），模型只需填数据，不必每次重新设计布局。或者在 `references/` 中加一个 `data-chart-examples.md`，包含已验证过的 HTML/CSS 片段供参考。

---

### 问题 3：抓取容错不够健壮（-4分）

- [ ] **待改进**

- 模式 A 的 5 个渠道并行抓取，如果 3 个以上失败，剩余素材不足以生成 5 条选题，但 skill 没有处理这个场景
- 模式 B 的 agent-browser 失败后只输出"抓取失败"，没有降级策略（比如退回到纯 WebSearch 结果）
- 渠道 URL 硬编码，如果某个站改版或封禁爬虫，需要改 SKILL.md 本体

**建议**：
- 加一条规则："如果成功抓取的渠道少于 3 个，告知用户并用已有素材尽量生成选题"
- 模式 B 加降级："如果 agent-browser 无法访问，直接使用 WebSearch 摘要作为素材"
- 考虑把渠道列表抽到 `references/channels.md`

---

### 问题 4：字数控制缺少机制保障（-1分）

- [ ] **待改进**

700-900 字的硬限制写在了 skill 里，但模型经常写超。虽然有"超字删减"步骤，但这是靠模型自觉执行的。

**建议**：在写作流程最后加一步明确指令："写完后用工具统计字数（`wc -m` 或 Bash 计算），如果超过 900 字，必须删减后再展示给用户。"

---

### 问题 5：缺少示例输出（-1分）

- [ ] **待改进**

skill 有很好的格式模板，但没有一篇完整的示例文章展示最终效果。模型第一次执行时缺少"标杆"参考。

**建议**：在 `references/` 中加一个 `example-output.md`，放一篇实际产出的完整文章（含 frontmatter），作为质量对齐的锚点。

## 四、综合评价

这是一个**完成度很高的生产级 skill**。它最大的价值在于：

1. **真正的端到端自动化**——不是"帮你写个文案"，而是从抓取热点到发布到微信草稿箱的完整工作流
2. **写作质量有制度保障**——style-guide 不是泛泛而谈，而是用禁止表和具体示例把"AI味"按住了
3. **交互设计尊重用户**——5 个确认点让用户始终有控制权

主要提升空间在**容错健壮性**和**数据图模板丰富度**。如果把数据图模板做扎实，再加上渠道抓取的降级策略，这个 skill 可以到 90+ 分。
