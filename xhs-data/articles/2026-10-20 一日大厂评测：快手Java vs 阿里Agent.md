# 一日大厂评测：快手Java vs 阿里Agent

主包从快手 Java 后端跳到阿里做 Agent
最大的感受是：工作时间变少了（0.5h😢），工作还是一样充实（夸～）


🌲 快手 Java 后端的一天（10:00-22:00）
10:00 到工位：先看告警群和监控大盘，没有红就是好日子
10:30 开会/带薪拉x：早上一般需要对齐一下今日的工作进度，没有对的话就带薪拉x
11:00 写代码：CRUD工程师启动！
12:00 午饭 + 午休
14:00 写代码：coding...
16:00 休息一下，拉个小伙伴逛逛元中心，回来继续coding...
18:00 晚饭
19:00 开会～无尽地开会
20:30 写代码；如果发版的话：发布窗口，盯着灰度看监控
22:00 没问题，下班回回龙观～🚕


🌲 阿里 Agent 开发的一天（9:30-21:00）
9:30 到工位：也要看告警群和监控大盘，以及token消耗大盘
10:00 复盘昨天数据（程序员两大疑问：为什么出问题了？为什么没出问题？）
11:00 跟产品掰扯 Agent 为什么又幻觉了
12:00 午饭
13:30 跑评测集，改Prompt
15:00 写 skill、搭 workflow，把业务经验喂给现成的 Agent
17:00 休息一下，拉个小伙伴逛逛笑脸公园，回来继续coding...
18:00 晚饭
19:00 发版本，盯监控和线上 bad case（或者是开会...）
21:00 下班，脑子里还在想那个没复现的幻觉🫠
真实感受：Agent开发不是天天造火箭，大部分时间在调Prompt、写skill、跑评测...
