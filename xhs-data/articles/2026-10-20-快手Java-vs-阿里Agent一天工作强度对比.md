# 快手 Java vs 阿里 Agent，一天工作强度对比

先说结论👇

主包从快手 Java 后端跳到阿里做 Agent

最大的感受是：**活没有变少，只是累的点换了**🤓

Java 累在需求多、链路长

Agent 累在结果不确定、要一直调

.

🌲 快手 Java 后端的一天（10:00-22:00）

10:00 到工位，先看告警群和监控大盘，没有红就是好日子

10:30 需求评审，产品在讲 PRD，主包脑子里已经在画接口和表结构

11:00 写代码：RPC 接口 + 缓存 + 配置中心，一套组合拳

12:00 午饭 + 午休

14:00 联调，跟上下游对字段："你传的是 String 还是 Long？"😅

16:00 查慢 SQL，加索引、改查询，压测过了才敢提

18:00 晚饭

19:00 Code Review，补单测

20:30 发布窗口，盯着灰度看监控

22:00 没问题，下班打车🚕

👉 关键词：**确定性**。代码写对了，结果就是对的。

.

🌲 阿里 Agent 开发的一天（9:30-21:00）

9:30 第一件事：看昨晚的链路追踪和 token 消耗，生怕哪个环节跑飞

10:00 修工具调用超时，加重试和熔断（Java 那套直接复用）

11:00 跟产品掰扯 Agent 为什么又幻觉了

查下来是召回不准，Prompt 也写得像流水账，两边都有锅

12:00 午饭

14:00 跑评测集，改一版 Prompt

这个 case 好了，另一个又挂了，打地鼠实锤

16:00 写 skill、搭 workflow，把业务经验喂给现成的 Agent

18:00 晚饭

19:00 发版本，盯监控和线上 bad case

21:00 下班，脑子里还在想那个没复现的幻觉🫠

👉 关键词：**不确定性**。同样的输入，今天对，明天不一定对。

.

🌲 对比下来的 3 个真实感受

1️⃣ 工时差不多（快手 12h vs 阿里 11.5h），心累的点不一样

Java 是活多，Agent 是活玄

2️⃣ Java 底子没白练

异常兜底、熔断降级、链路追踪、并发，到了 Agent 这边全都用得上

3️⃣ Agent 开发不是天天造火箭

大部分时间在调 Prompt、写 skill、跑评测

.

🌲 给想转 Agent 的后端同学

先别急着背一堆框架名词

把工程化兜底的能力带过去，这才是后端转 Agent 最大的优势

.

你觉得哪种更累？评论区聊聊👇

想转 Agent 又不知道简历怎么写的，也可以来找主包🤓
