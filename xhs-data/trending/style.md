## 爆款规律

### 两类爆款，驱动指标不同
| 类型 | 典型 | 数据特征 | 用户动作 |
|------|------|----------|----------|
| 干货路线/清单 | Agent三周速成路线、3000份简历 | 收藏 ≥ 点赞（6664藏/4198赞） | 收藏备用 |
| 经历/情绪/暴论 | 大厂8年赚了多少、29岁Java女转Agent、秋招暴论 | 评论高（400~500） | 评论站队、共鸣 |

### 赛道热度
- **Agent开发是最热子赛道**：精读 10 篇里 5 篇来自它，覆盖路线、转型、祛魅、质疑、日常 5 种角度
- 薪资/选 offer 话题评论最多，天然有争议
- 纯图片笔记（正文<100字）占高赞的一部分，但无法学文字结构，已剔除

## 选题方向
1. **Agent 学习路线**：按天/周拆计划，附仓库、项目、简历写法（收藏型）
2. **Java → Agent 转型**：身份标签 + 时间线 + 结果（共鸣型）
3. **大厂 Agent 真实在做什么**：祛魅、"面试造火箭进去写 skill"（反差型）
4. **Agent 工程化价值之争**：模型变强后工程化是否伪需求（争议型）
5. **工作强度日常**：「X K Agent 开发一天」时间轴（系列型，17k/18k/30k 都有人做）
6. **薪资/选 offer**：真实数字 + 暴论观点
7. **面试官视角**：问答复盘，🎯问 💡答

## 写作技巧
- **开头一句给身份+结果**："agent零基础，自学30天拿到400/day实习"、"29岁Java女被裁后转Agent上岸"
- **结构**：
  - 路线类：Day 0-2 / Day 3-10 … 分阶段，每段一句目标+具体做法
  - 日常类：9:00 / 9:30 … 时间轴，每条带一个吐槽
  - 面经类：🎯我问 / 💡她答
  - 经历类：时间顺序叙事，关键节点给数字
- **数字要具体**：400/day、QPS 500→3000、480万、日薪1200、3000份简历
- **情绪词**：人麻了、脑壳疼、悔不当初、被自己蠢哭
- **反常识钩子**："面试造火箭，进去打螺丝"、"无脑选薪资最高"
- **自称**："主包"在校招生作者里常见
- **结尾**：互动引导（"还想看什么评论区告诉我"）或一句金句收束
- **标签**：5~10 个，混合大类（#互联网大厂 #程序员）和精准词（#agent开发 #大模型应用开发）
