## 正文

本人情况：agent相关方向零基础，自学30天拿到400/day实习
时间和计划如下
主要是围绕三个github仓库学（见图）
	
ps不是学完所有东西才开始，基本上是边学边做
	
Day 0-2：Agent 名词扫盲
先把 Agent、RAG、Tool Calling、Function Calling、Memory、Planner、Executor、LangGraph、MCP 这些常见词过一遍，这样后续看文档不会一头雾水
	
Day 3-10：看 all-in-rag （图1仓库）+ vibe coding 一个 RAG 项目
开始系统看 RAG 主线：文档处理、切分、向量检索、混合检索、Rerank、多跳检索、评测指标。
看完后没有继续空学，直接 vibe coding 了一个 RAG 项目，把流程先跑通。
	
Day 11-20：看 AgentGuide + 做一个多 Agent 项目
接着看 AgentGuide，补 Agent 工程化相关内容，比如 LangGraph、状态机、工具调用、记忆管理、兜底机制、护栏。
边看边做Agent 项目，可以参考别人的项目或者买一个
	
Day 21-30：看 AI Agent 面试资料 + 整理项目表达
最后主要看 AI Agent 面试 guide，整理项目怎么讲
重点准备：项目架构、为什么这么设计、每个模块怎么实现、指标怎么测、失败怎么兜底
	
每天刷 Hot100  ，保持手感
	
简历方面：两个项目一个rag一个agent
	
rag：不能是简单的rag项目，要结合all in rag里的rag自我反思，agentic rag去做一个复杂度足够的rag项目
	
agent：参考来源的agent项目，可以做coding agent，各种电商客服agent
