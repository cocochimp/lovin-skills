# Insights (规则库)

> 复盘结论的唯一落点。每条规则由 xhs-review 复盘提炼，写作者（xhs-writes）写作前必读。
> 状态机：pending(待验证) → active(有证据) → invalid(证伪废弃)。
> 更新：每次复盘只增改，不推翻无证据的旧规则；改动需用户确认。

## 规则列表

- id: R01
  假设: 标题含具体数字（3w/2000份/10倍）比模糊词收藏率高
  证据: 月薪篇(卡片64) vs 竞赛篇(6)；爆款《投了3000份简历》(2854赞)、《校招月入2万5》(1430赞)
  强度: 高  状态: active
  应用: 标题阶段强制检查，数字式模板优先

- id: R02
  假设: 薪资/到手钱话题评论密度高（争议即流量）
  证据: 月薪篇 20评/3905浏览；爆款《秋招暴论：无脑选薪资最高》(2330赞) 评论高
  强度: 高  状态: active
  应用: 选题配额 30% 真相类的来源；标题可用"到手变2w？"式提问

- id: R03
  假设: 收藏型内容（路线/清单/模板）收藏≥点赞，是涨权重主引擎
  证据: 爆款《Agent三周速成路线》6664藏/4198赞；《3000份简历》收藏高
  强度: 高  状态: active
  应用: 内容配比 60% 方法论；每篇必须有可保存的清单/模板/话术

- id: R04
  假设: 个人经历+身份钩子（双厂/转型亲历）能提转化，但话题必须主流
  证据: 竞赛篇(6赞)失败=小众话题；月薪篇成功=主流话题+数字
  强度: 中  状态: active
  应用: 选题校验：话题属于主流爆款池（薪资/转型/面试/简历），再叠加个人钩子

- id: R05
  假设: "时间差/市场错配"钩子（Agent才1岁市场要5年经验）短期爆发力强
  证据: 爆款 3688赞；同类"Agent明年被取代"(556赞)
  强度: 中  状态: pending
  应用: 选题池 T03；需本人发文验证后转 active

- id: R06
  假设: 浏览→收藏转化（藏赞比）是内容健康度核心，>0.5 为收藏型成立
  证据: 月薪篇 6藏/16赞=0.38（未达标，缺收藏钩子）；爆款路线类 >1
  强度: 中  状态: active
  应用: 写作前收藏钩子自查；复盘时用藏赞比排序判断选题方向

- id: R07
  假设: 发布时间与流量关系（待验证）
  证据: 无
  强度: 低  状态: pending
  应用: 待积累发布时间数据后验证
