# 封面图规格

## 封面方案选择（交互确认）

生成 3-5 组封面方案供用户选择，每组包含：
- 主标题（2行，第一行包含内容主体并设置悬念，第二行给出核心观点/结论，标注哪些关键词用红色高亮）
- 副标题（1行补充概述）
- 右侧背景数字（一个量化指标，如有）

注意：主标题必须是2行，且两行之间是递进关系——第一行点明内容主体（如公司名、人名、事件名）并引发好奇，第二行揭示答案。不能把一句话硬拆成两行。

展示格式：
```
请选择封面方案：

方案1:
  主标题:
    L1: 英伟达Q1：交出史上最强财报
    L2: <red>真正赢家</red>只有一个
  副标题: 英伟达Q1财报揭示算力经济新格局
  背景数字: $441B

方案2:
  主标题:
    L1: 英伟达：数据中心收入<red>暴涨73%</red>
    L2: 黄仁勋到底押对了什么
  副标题: 三条增长曲线背后的算力垄断逻辑
  背景数字: 73%

方案3:
  ...
```

用户选定后再执行以下步骤生成封面图。

## 封面设计规范（三要素）

- **主标题**：固定2行（L1引发好奇 + L2揭示观点），部分关键词用红色（`var(--accent)` #E94560）标注，简洁吸引但不做标题党
- **副标题**：1 行补充概述，浅色（`var(--ink-light)`）
- **右下角背景数字（如有）**：一个量化指标（如 $441B、72%、10x），大字号低透明度（`rgba(accent, 0.15)`），作为视觉点缀

## 生成步骤

1. 根据用户选定的封面方案，组装标题 HTML
   - 红色关键词用 `<span class="accent">关键词</span>` 包裹
   - **换行规则**：标题超过10个中文字时，手动用 `<br>` 分行，确保文字不溢出封面
2. Read `assets/cover_template.html`
3. 填充占位符：
   - `{{TITLE_HTML}}`：封面大标题（含红色标注的 span）
   - `{{SUBTITLE}}`：副标题文字
   - `{{CUSTOM_CSS}}`：自定义样式，包含右下角背景数字的实现：
     ```css
     .cover::after {
       content: "数字内容";
       position: absolute;
       right: 40px;
       bottom: 30px;
       font-size: 120px;
       font-weight: 900;
       color: rgba(233, 69, 96, 0.15);
       z-index: 0;
     }
     ```
4. Write 到 `/tmp/gzh_cover_{YYYY-MM-DD}-{关键词}.html`
5. 截图：`node .claude/skills/gzh-writes/assets/capture.js /tmp/gzh_cover_{YYYY-MM-DD}-{关键词}.html docs/pic/gzh-cover-{YYYY-MM-DD}-{关键词}.png 1080 608`
6. 执行「图片质量自审」流程（详见 `references/image-review.md`）
