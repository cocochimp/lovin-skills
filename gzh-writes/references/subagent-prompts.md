# SubAgent Prompts

## 模式 A — 渠道抓取 prompt（所有渠道统一使用）

~~~
你的任务是抓取 {URL} 的热门标题 3-5 条。

步骤1（WebFetch 优先）：使用 WebFetch 工具访问 {URL}，从返回内容中提取热门文章标题和链接。

步骤2（Fallback）：如果 WebFetch 失败或提取不到有效标题，再使用 Skill 工具调用 agent-browser 技能，用浏览器自动化能力：
1. navigate 到 {URL}
2. 等待页面加载完成
3. snapshot 获取页面内容
4. 从 snapshot 中提取标题列表

如果两种方式都失败，返回"抓取失败"。

输出格式：每行一个标题，编号列出，每条附带文章链接（如能获取）。格式如下：
1. 标题文字 | 链接URL
2. 标题文字 | 链接URL
~~~

## 模式 B — 主题搜索 prompt

```
你的任务是搜索"{用户传入主题}"相关的最新资讯和深度分析。

步骤1：用 WebSearch 搜索"{用户传入主题}"，获取最新的 5-10 条相关结果。

步骤2：对搜索结果中最相关的 3-5 条，优先使用 WebFetch 访问 URL 并提取内容摘要。

步骤3：如果 WebFetch 失败或内容不足，再使用 Skill 工具调用 agent-browser 技能，用浏览器自动化访问这些 URL 并提取内容摘要。

如果两种方式都失败，输出"抓取失败"。

输出格式：
1. 标题 | 链接URL | 一句话摘要
2. 标题 | 链接URL | 一句话摘要
```

## 选题展示格式

```
1. [标题]（36氪/财联社/虎嗅/钛媒体/界面新闻）
   URL（如有）
   论点：一句话核心观点
   角度：切入视角说明
   争议点：可能引发的讨论方向
```

- 展示 5 条选题后，末尾提示：`输入"更换"可获取下一批选题`
- **"更换"机制**：用户输入"更换"时，从第一次抓取缓存的剩余素材中重新生成 5 条选题（无需重新抓取）
- 等待用户选定后进入下一步
