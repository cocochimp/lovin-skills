# Writing Style (个人写作风格库)

> 学习一次、固化复用。写作前必读；只有用户主动要求"学习我的风格"或复盘确认后才更新。
> 每条特征尽量带证据来源（哪篇文章支撑），更新时保留证据。

## Style Snapshot
- 来源样本: 已发布文章（《大厂月薪3w，到手变2w？》等）+ 用户确认
- 学习日期: 2026-10-22
- 置信度: 中（样本 3 篇，待更多发布后复核）

## 标题偏好
- 提问式 + 数字 + 个人经历：如「大厂月薪3w，到手变2w？」
- 痛点/热点词：薪资、到手、大厂、简历、面试
- 避免：泛话题（如"五险一金"扣款）、小众话题（如"竞赛"）——有数据教训
- 数字要具体可感：3w、2w、10倍、3000份

## 语言特征
- 口语化、接地气、有情绪、有态度、有幽默
- 短句为主，多换行，小红书扫读友好
- 具体数字优先于形容词
- 自称："主包"（接地气）+ "我"（直接）
- 少用书面连接词、少大词堆叠、不强行升华

## 结构模式
- 结论先行（开头一句给身份+结果）
- 板块分点：🌲 分段 + 1️⃣2️⃣3️⃣ 列举
- 算账/清单/对比类结构表现最好（月薪篇：算笔账→福利→代价）
- 真实场景 + 前后对比 + 边界判断，不堆卖点
- 结尾：互动引导（"评论区聊聊"）或收在具体动作上，不写金句升华

## Emoji 用法
- 🌲 分段
- 1️⃣2️⃣3️⃣ 列举
- 🤓😅🫠 调侃/无奈（克制，不用来遮空）

## 禁忌清单（AI 味雷区）
- 不用"从来不是 A 而是 B""看不见的细节"等对仗金句
- 不四字名词冒号清单（每条同句式、同长度）
- 不结尾升华到"生活质感/松弛感/答案"
- 不编造数字、经历、评论、效果（数字必须真实）
- 不散文化：保留标题/钩子/分段/标签/互动
- 不自称每篇提"双非逆袭"

## 收藏钩子检查（每篇必过）
- 读者为什么收藏我？（清单/模板/话术/路线，至少一个可保存物）
- 无收藏理由 → 打回补内容

## 标签习惯
- 5~10 个，混合大类（#互联网大厂 #程序员）和精准词（#Agent开发 #大模型应用开发）
