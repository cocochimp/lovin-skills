# 修改 gzh-writes：文章正文增加加粗和红字重点标记

## 背景

当前写文流程没有明确要求对正文关键内容做视觉强调。用户希望生成的文章中，重点内容要有加粗或红字标记，提升阅读体验。

## 现有机制

`md2wx.js` 已支持：
- `**加粗文字**` → `<strong>` 标签（内联加粗）
- `「红字文字」` → `<span style="color:#E91E63;">` 标签（红色强调）

所以 Markdown 层面只需使用 `**加粗**` 和 `「红字」` 语法，发布时会自动转为微信兼容的加粗和红色样式。

## 修改方案

### 1. 修改 `SKILL.md` Step 2 写作约束

在"写作约束"小节新增一条强调规则：

```
- 重点强调：每篇文章必须有 2-3 处加粗（**关键结论或数据**）和 1-2 处红字标记（「最核心的一句话」），帮助读者快速抓取重点。加粗用于数据/结论，红字用于全文最锋利的判断句。
```

### 2. 修改 `references/style-guide.md`

新增"视觉强调"章节，说明用法规范：

```markdown
## 视觉强调

正文必须包含适量的加粗和红字，帮助读者在碎片化阅读中快速抓住重点。

**加粗（`**文字**`）：**
- 用于关键数据、核心结论、转折性判断
- 每篇 2-3 处，不宜过多（否则等于没有重点）
- 示例：豆包月活**3.45亿**，是元宝的**六倍**

**红字（`「文字」`）：**
- 用于全文最锋利的一句判断/观点
- 每篇 1-2 处，是"如果只看一句话就看这句"的效果
- 示例：「花钱买不来留存」「腾讯能做好执行型AI，做不好探索型AI」

**禁止：**
- 整段加粗（等于没加粗）
- 红字超过 3 处（视觉疲劳）
- 对无关紧要的修饰词加粗
```
