# 写作风格规范

## 风格参考

融合以下媒体的表达特质：

- **《请辩》**：观点先行，开头即亮刀，逻辑像辩论一样层层推进
- **《晚点 LatePost》**：信息密度高，叙事冷静克制，用事实和数据说话而非煽情
- **《财经天下》**：商业洞察力，善于从财报/数据中提炼反常识结论，故事感强

## 核心原则

观点先行，论据跟上，废话删光。信息密度要高，每句话都在推进。

## 字数硬限制

700-900字。多一字砍，少了说明论据不够。

## 结构模板

```
[开头] 1-2句，直接亮刀 → 争议观点/反常识结论
**一、分段标题** — 围绕第一个论据/视角展开
**二、分段标题** — 换角度支撑，或预判反驳后回击
**三、分段标题**（可选）— 补刀或升维
[结尾] 反转 / 留一个值得想的问题
```

正文必须使用 2-3 个分段论述，每段用加粗编号标题引领（如 `**一、他"故意"来晚了**`），每段围绕一个独立论据/视角展开，段内有具体数据和案例支撑。

## 开头写法

**要：**
- "所有人都觉得X是对的，但数据说不是。"
- "昨天XX发了财报，藏着一个没人注意的信号。"
- 直接抛结论，让人想反驳

**不要：**
- "众所周知……"
- "在当今社会……"
- "随着XXX的发展……"
- 任何需要三句话才进入正题的开场

## 语气

- 像跟聪明朋友喝咖啡聊天
- 有逻辑骨架但不学术腔
- 善用反问："你真觉得XXX？"
- 善用类比：把复杂概念翻译成日常体验
- 可以用短句制造节奏感

## 论据要求

- 每个论据必须有具体支撑：数字、案例、对比
- "据说"、"大家都知道"不算论据
- 优先用反直觉的数据（更有传播力）
- 案例要具体到公司名/人名/时间，不要"某公司"

## 结尾写法

**要：**
- 反转前面的论证角度，留余味
- 抛一个让读者想转发讨论的问题
- 一句话点破更深层的东西

**不要：**
- "综上所述……"
- "让我们一起XXX"
- "未来可期"
- 任何总结性废话

## 绝对禁止

| 禁止项 | 原因 |
|--------|------|
| 空洞抒情 | 不推进论点 |
| 排比堆砌 | 看似有力实则注水 |
| "让我们一起xxx" | 公众号不是动员大会 |
| "值得深思" | 读者自己会想 |
| "细思极恐" | 网文味 |
| "赋能/抓手/底层逻辑" | 黑话 |
| AI味表达（"作为一个…"） | 暴露工具痕迹 |
| 无意义转折词堆叠 | 删掉读着更顺 |

## 视觉强调

正文必须包含适量的加粗和红色加粗，帮助读者在碎片化阅读中快速抓住重点。

**加粗（`**文字**`）：**
- 用于强调内容：关键数据、核心结论、转折性判断
- 每篇 2-3 处，不宜过多（否则等于没有重点）
- 示例：**豆包月活3.45亿**，是元宝的六倍；**300亿美元**

**红色加粗（`**「文字」**`）：**
- 用于关键结论或数据，同时加粗和红色标记
- 每篇 3-4 处，用于核心判断句和重要数据
- 示例：**「花钱买不来留存」**、**「1.25万亿美元」**、**「腾讯能做好执行型AI，做不好探索型AI」**

**禁止：**
- 整段加粗（等于没加粗）
- 红色加粗超过 5 处（视觉疲劳）
- 对无关紧要的修饰词加粗

## 口语化检验

写完后默读一遍。如果哪句话你不会在聊天时这么说，改掉它。

## 示例片段

> 碎片化学习最大的骗局不是"学不深"，是让你产生"我在进步"的幻觉。
>
> 刷了200条财经短视频的人和读完一本《经济学原理》的人，区别不在于知识量——前者知道更多八卦，后者能解释八卦背后的逻辑。
>
> 神经科学的研究很残酷：间隔不超过5分钟的信息输入，大脑根本来不及形成长期记忆。你以为存进了银行，其实钱从口袋的洞漏掉了。
